# Perguntas para Entrevistas Técnicas em Java

Bem-vindo ao material de estudo para entrevistas técnicas de Java!

Este site contém perguntas e respostas organizadas por domínio, cobrindo desde fundamentos da linguagem até práticas profissionais.

## Conteúdo

- **Java Core** — Fundamentos, OOP, Exceções, Collections, Java 8+, Multithreading, Generics e Testes
- **Spring Boot** — Conceitos básicos, Beans, API REST, Security e tópicos avançados
- **JPA e Hibernate** — Fundamentos, mapeamento, consultas, transações e Spring Data JPA
- **SQL e Bancos de Dados** — Fundamentos de SQL e modelagem relacional
- **Ferramentas** — Maven e GIT
- **Práticas Profissionais** — Troubleshooting, Code Review e Documentação

## Como usar

Navegue pelo menu lateral para acessar cada tema. As perguntas são numeradas dentro de cada domínio e incluem respostas com correções didáticas.
